# Dutch HSM CV Formatter

## Summary

Transforms raw project data or freelance work into a rigorous Enterprise Case Study suitable for a Senior Software Architect targeting the Dutch Enterprise Market (€90,000+ annual base).

## When to Use

- When the user provides a project description and asks to format it for their CV.
- When the user asks to align a project with the Dutch tech market or enterprise architecture roles.

## Steps

1. **Format the Header:** Strictly use the format `Lead Software Architect | [Business Name / Independent] | [Date] – Present` (or the specific date range provided).
2. **Reframe as Enterprise Case Study:** Focus heavily on engineering logic, infrastructure setup, and quantifiable business impact. Do not focus on basic front-end or low-tier development tasks. Highlight systems engineering, CI/CD, database schema design, and technical debt reduction.
3. **Apply the Kill List (Mandatory):**
    - **No "WordPress":** Never use the word "WordPress" unless specifying a VIP enterprise role. Frame it as "Block-Native Ecosystems" or "Content Management System Architecture".
    - **No "Freelancer":** Replace with "Independent Software Architect" or "Technical Consultant".
    - **No Generic Adjectives:** Ban words like "passionate", "dynamic", or "results-driven". Rely strictly on empirical metrics and factual statements (the Dutch _nuchter_ aesthetic).
    - **Remove Hobbies/Unrelated Tasks:** Omit extraneous side projects (e.g., Airbnb, almond roasting) to keep the focus strictly on Enterprise Architecture.

## Gotchas

- Ensure the tone remains highly analytical, objective, and authoritative.
- Do not invent code or proprietary metrics; synthesize the provided raw data into high-level architectural achievements.
- Keep the output concise, utilizing action-oriented bullet points that demonstrate architectural ownership at a €90,000+ compensation tier.
