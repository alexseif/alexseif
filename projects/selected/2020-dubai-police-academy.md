# Software Architect & Full-Stack Developer | Dubai Police Academy (2021)

## Overview
Refactored, upgraded, and prepared a compliance-driven Learning Management System (LMS) codebase for the Dubai Police Academy prior to an external DevOps handoff. Upgraded legacy Moodle core dependencies and verified database schema migrations to preserve student progression records and audit logs.

Integrated custom landing pages and interface components directly into the LMS template engine while maintaining clean separation from core framework code. Evaluated client DevOps infrastructure plans, identified severe runtime incompatibilities with a proposed Windows Server deployment, and enforced Linux/Apache infrastructure baselines to guarantee system stability and prevent technical debt.

## Key Technologies & Tools
* PHP (runtime modernization and module refactoring)
* Moodle LMS (enterprise distribution upgrade and template hooks)
* MySQL (audit trail integrity and schema migration validation)
* Linux / Apache HTTP Server (infrastructure baseline specification)
