# Lead Full-Stack Engineer & Architect | Egyptian Ministry of Interior (Aman) | 2020

### Context & Scale
The Egyptian Ministry of Interior (contracted via iSoft) operates the national Aman vehicle technical inspection network. Municipal traffic departments faced severe daily congestion during mandatory annual vehicle registration renewals. The ministry required a secure, high-concurrency digital reservation and geographic dispatch engine to validate vehicle registration records against central state databases and route motorists to decentralized commercial centers and mobile inspection vans across Egypt. Retained as Lead Full-Stack Engineer and Architect to design platform architecture, implement custom integration modules, and establish secure government API communication boundaries.

### Architectural Decisions
- **Secure State API Integration:** Engineered an authenticated, encrypted API gateway linking the public web tier to restricted ministry backend databases, enforcing mutual TLS, strict JSON schema validation, and rate limiting.
- **Spatial Proximity and Capability Routing:** Designed database query routines matching citizen appointment requests against mobile unit availability based on geographic coordinate proximity and specific vehicle diagnostic hardware constraints (such as diesel emissions sensors or heavy axle rollers).
- **Transactional Slot Locking:** Implemented pessimistic row-locking on appointment slot entities in MySQL to eliminate double-booking race conditions during nationwide peak renewal rush hours.
- **Phased Multi-Governorate Rollout:** Architected a modular rollout strategy that launched digital appointments in high-density pilot governorates before expanding across the entire national network of static centers and mobile vans.

### Engineering Execution
- **Custom Drupal Application Tier:** Developed custom Drupal modules in PHP 7 handling multi-step appointment registration, vehicle plate validation, national ID verification, and digital receipt generation.
- **Spatial Database Indexing:** Implemented MySQL spatial data types and coordinate distance formulas to calculate nearest available inspection units within acceptable driving radii.
- **Administrative Oversight Logging:** Built comprehensive audit logging capturing booking lifecycle events, slot cancellations, and field inspection completion timestamps for ministry supervisory dashboards.

### Measurable Impact
- **Physical Traffic Decentralization:** Successfully diverted substantial vehicle inspection volumes away from congested municipal traffic police departments into distributed commercial centers and mobile units.
- **Zero Booking Conflicts:** Pessimistic slot locking completely prevented appointment collisions across thousands of concurrent daily inspection bookings.
- **High-Volume Availability:** Sustained reliable uptime during national end-of-month license renewal surges with zero state corruption or lost transactions.
